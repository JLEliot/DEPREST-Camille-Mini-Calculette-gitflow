# Mini calculette (workflow Git inspiré GitFlow)

## Objectif
Calculette web simple (HTML/CSS/JS) avec 3 opérations.

## Fonctionnalités
- ✅ Addition (a + b)
- ✅ Soustraction (a - b)
- ✅ Multiplication (a * b)

## Utilisation
Ouvrir `index.html` dans un navigateur.

Dernière mise à jour : branches A et B fusionnées

## Notes Git
Un conflit volontaire a été créé et résolu sur ce projet afin de démontrer
la compréhension du mécanisme de résolution de conflits Git.

## Workflow Git
Ce projet utilise un workflow Git inspiré de GitFlow :

- `main` : version stable finale
- `develop` : branche d’intégration
- `feature/*` : développement des fonctionnalités

Chaque opération (addition, soustraction, multiplication) a été développée
dans une branche dédiée puis fusionnée progressivement dans `develop`.

Un conflit volontaire a été provoqué sur le fichier `README.md` afin de
démontrer la compréhension et la résolution manuelle des conflits Git.
